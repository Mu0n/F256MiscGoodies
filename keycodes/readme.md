These files were made with https://www.keyboard-layout-editor.com/#/

**f256k2_base.json**: base file with just the keycap information, no raw codes in hex. Represents both the F256K and F256K2.

**f256k2_codes.json**: base file with just the keycap information, no raw codes in hex. Represents both the F256K and F256K2.

If you want to edit them as a starting point for your needs, then go to that website's 'Raw Data' tab, click on 'Upload JSON' and send one of these files to it.
